# archestra Provider

The Archestra provider lets you manage Archestra resources (agents, MCP servers, identity providers, teams, LLM keys, security policies, organization settings) as code. Authenticate with an API key, or with workload identity: the provider exchanges an OIDC token from the workload's own identity provider for a short-lived service account token. Every configuration value can — and should — be supplied via environment variables so secrets never enter HCL.

## Example Usage

```terraform
terraform {
  required_providers {
    archestra = {
      source = "archestra-ai/archestra"
      # Read MIGRATION-v3.md before upgrading from 2.x.
      version = "~> 3.0"
    }
  }
}

provider "archestra" {
  # The Archestra release you approved. See the API compatibility guide.
  api_version_constraint = "= 1.4.1"

  # base_url and api_key are read from the environment by default —
  # don't commit secrets to source.
  #   export ARCHESTRA_BASE_URL="https://archestra.your-company.example"
  #   export ARCHESTRA_API_KEY="arch_..."   # mint via Settings → API Keys
  #
  # Or sign in with workload identity instead of an API key:
  #   export ARCHESTRA_SERVICE_ACCOUNT_ID="<service account ID>"
  #   export ARCHESTRA_OIDC_TOKEN_FILE="/var/run/secrets/archestra/serviceaccount/token"
}
```

## Schema

### Optional

- `api_key` (String, Sensitive) **Required for any operation that talks to the Archestra API.** Marked Optional in the schema only so the value can be supplied via the `ARCHESTRA_API_KEY` environment variable instead of inline HCL — prefer the env var to keep secrets out of source control. Mint a key in the Archestra UI under Settings → API Keys (the value starts with `arch_`). Not needed when `service_account_id` is set.
- `api_version_constraint` (String) Optional constraint on the remote Archestra server version, for example `= 1.4.0-rc.55`. Checked using GET /health before resource operations. A constraint requires readable semantic version metadata. The provider always rejects versions below its required API floor and warns about versions outside its tested interval. This does not select the Terraform provider version. See the API compatibility guide.
- `base_url` (String) Base URL of the Archestra API (for example, `https://archestra.your-company.example`). Defaults to `http://localhost:9000` if neither this attribute nor `ARCHESTRA_BASE_URL` is set. Also reads from the `ARCHESTRA_BASE_URL` environment variable.
- `oidc_token` (String, Sensitive) OIDC token to exchange for a service account token. Also reads from the `ARCHESTRA_OIDC_TOKEN` environment variable. Set this or `oidc_token_file` with `service_account_id`.
- `oidc_token_file` (String) Path to a file holding the OIDC token, such as a projected Kubernetes service account token. Read again on every exchange, so a rotated token is picked up. Also reads from the `ARCHESTRA_OIDC_TOKEN_FILE` environment variable.
- `service_account_id` (String) ID of the service account to act as with workload identity, instead of an API key. The account needs a federated credential that trusts the OIDC token. Requires an Enterprise license. Also reads from the `ARCHESTRA_SERVICE_ACCOUNT_ID` environment variable.
